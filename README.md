# Coffee

## Опис
"Coffee" — сайт для бренду кави, який демонструє різноманіття кавових сортів та їх особливості. Сайт включає в себе сторінки для кожного сорту кави, опису, а також інтерактивні елементи для зручності покупців.

## Технології
- HTML5
- SCSS
- JavaScript
- Адаптивна верстка (Flex, Grid)
- Інтерактивні елементи (меню, слайдери, модальні вікна)

## Демо

[Live Demo](https://vitiok2021.github.io/Coffee/) — сайт для бренду кави

## Особливості
- Адаптивний дизайн, оптимізований для всіх пристроїв
- Зручний інтерфейс для перегляду інформації про різні сорти кави
- Інтерактивні елементи для покращення взаємодії з користувачем
